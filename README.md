# Pedro Satin

Software engineer at [Saúde Bliss](https://github.com/saudebliss) and university professor at [UniCesumar](https://github.com/unicesumar), based in Brazil.

I build web applications and automations, and publish tools I use in my own work. I also teach generative AI and software development with agents.

## Selected projects

- [Palpitae](https://github.com/pedrosatin/palpitae): football prediction pools with private groups and leaderboards. React, TypeScript and Cloudflare Workers. [Try it](https://palpitae.com.br).
- [K-pop Quiz](https://github.com/pedrosatin/kpop-quiz): daily quizzes and puzzles in Portuguese and English, with sources recorded for the answers. Astro, Preact and Python. [Play](https://kpopquiz.online).
- [Skills](https://github.com/pedrosatin/skills): reusable agent workflows, including my tools for Portuguese writing and JavaScript/TypeScript complexity checks. Original work and third-party adaptations are documented separately.
- [Software development with agents](https://github.com/pedrosatin/processo-software-agentes): teaching materials and executable examples covering Skills, MCP and specification, implementation and testing.
